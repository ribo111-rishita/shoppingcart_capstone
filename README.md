# 🌸 Flower Cart - Online Flower Shopping Website

A beautifully designed flower shopping website where users can browse and add flowers to a cart, with secure login and signup functionality. Built for a smooth and visually pleasing shopping experience.

## ✨ Features

- 🛍️ View and shop a variety of flowers
- 🧺 Add/remove flowers to/from cart
- 👤 Login & Signup system (client-side/session-based)
- 💅 Clean, elegant, and responsive UI
